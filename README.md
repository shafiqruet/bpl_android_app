## 📱 Overview

The **BPL Android App** is a comprehensive mobile application for cricket enthusiasts to follow the **Bangladesh Premier League**. Get real-time scores, match schedules, player statistics, team rankings, and exclusive highlights – all at your fingertips.

## ✨ Features

- 🎯 **Live Scores** – Real-time ball-by-ball updates
- 📅 **Match Schedule** – Full fixture list with reminders
- 📊 **Points Table** – Team rankings and net run rate
- 🏏 **Player Stats** – Batting, bowling, and fielding records
- 🗞️ **News & Updates** – Latest BPL headlines and transfers
- 🔔 **Push Notifications** – Match alerts and breaking news
- 📸 **Match Highlights** – Video clips and photo galleries
- 👤 **Fan Zone** – Predictions, polls, and fan interactions

## 🛠️ Tech Stack

- **Language** – Kotlin
- **Architecture** – MVVM + Clean Architecture
- **Networking** – Retrofit + OkHttp
- **Image Loading** – Glide / Coil
- **Database** – Room (local caching)
- **Dependency Injection** – Dagger Hilt / Koin
- **Asynchronous** – Coroutines + Flow
- **UI Components** – Material Design 3, Jetpack Compose (or XML views)
